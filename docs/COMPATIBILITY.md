# Compatibility / Compatibilidade

Only Garfield 2 Europe (`SLES-54172`, `627B8252`) is targeted. Other revisions, emulators and PCSX2 builds have not been validated in this package. The No Bloom patch does not permanently modify the game image. No official endorsement or Hardcore approval is claimed.

The existing 50 FPS patch is not distributed in this repository package. Test independently and document combined behavior before claiming compatibility. Do not earn competitive achievements while testing experimental patches; consult RetroAchievements maintainers and QA for official guidance. A new game hash is not created merely by placing a PNACH in the emulator's patch directory.

Somente a versão europeia indicada é alvo deste patch. Não há homologação oficial nem garantia de compatibilidade com outras revisões, modos de renderização ou patches combinados. As investigações devem ser feitas sem conquistas competitivas ativas.
