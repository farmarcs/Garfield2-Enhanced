# Compatibility / Compatibilidade

[English](#english) · [Português (Brasil)](#português-brasil)

## English

| Item | Status |
| --- | --- |
| Garfield 2 Europe, SLES-54172, CRC 627B8252 | Target revision; author-tested |
| Windows, PCSX2 v2.9.196, Direct3D 12 | Author-tested environment |
| Other game revisions, emulator builds and renderers | Not validated |
| Other patches | Comprehensive compatibility not established |
| RetroAchievements / Hardcore | No official approval |

The PNACH modifies emulated memory, not the original disc image. Merely installing a PNACH does not create a new game hash. Technical compatibility is not evidence of achievement eligibility. Keep achievements disabled during experimental testing and consult RetroAchievements maintainers for official guidance.

No Bloom is the only modification distributed here. See [technical notes](TECHNICAL.md) for the scope and limits of testing and the [installation guide](INSTALLATION.md#english) for rollback.

O PNACH modifica a memória emulada, não a imagem original do disco. A simples instalação de um PNACH não cria um novo hash do jogo. Compatibilidade técnica não implica autorização para obtenção de conquistas. Mantenha as conquistas desativadas durante os testes experimentais e consulte os mantenedores do RetroAchievements para orientação oficial.

O No Bloom é a única modificação distribuída aqui. Consulte as [notas técnicas](TECHNICAL.md#português-brasil) para o escopo e limites dos testes e o [tutorial de instalação](INSTALLATION.md#português-brasil) para desfazer a alteração.
